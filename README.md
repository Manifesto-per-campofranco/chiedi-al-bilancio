# Chiedi al bilancio

Strumento per fare domande, in parole semplici, sul bilancio del Comune di Campofranco (CL).
Risponde con i numeri dei rendiconti ufficiali pubblicati su BDAP e con i dati di cassa SIOPE.

È uno strumento indipendente: non è un servizio del Comune di Campofranco.
Lo ha realizzato un gruppo di lavoro che si occupa di contabilità e bilancio degli enti pubblici.

Lo strumento è in costruzione. Questi file servono alla macchina che fa girare il modello di linguaggio open source:
il modello legge soltanto la domanda, i numeri li calcola sempre un programma a partire dai dati ufficiali.
